This directory is the source of truth for the next ArchoSystem public website, private investor experience, and ArchoTank selector.

The current production website remains unchanged. This planning package exists to lock the strategy, disclosure boundaries, claims, visual direction, workflow, and definition of done **before** layout and implementation work begins.

## Governing rules

- Content and claims are approved before layout polish.
- The public site explains the product; the private investor experience reveals market scale, economics, and platform expansion.
- Protected construction terminology and proprietary details are not used casually in public marketing.
- Cinematic imagery must use one canonical ArchoTank visual language and must not imply untested performance.
- The selector begins as a transparent calculation and rules engine, not an AI quotation tool.
- Every settled decision is recorded in `DECISIONS.md`.
- Every performance or market claim is recorded in `CLAIMS_LEDGER.md`.
- New ideas that are not required for launch go to a later-version parking lot rather than reopening the active build.
- This planning branch must not modify the live homepage, production styles, or production scripts.
